# Security

Frequency SafetyProtocol is experimental and is not yet a production VPN or network-security product.

Please do not use public issues to post credentials, private network details, access tokens, personal location history or exploit material containing sensitive user data.

Security reports should describe:
- affected protocol invariant or component
- minimal reproduction
- expected vs observed authority
- whether the issue can widen authority, weaken fail-closed behavior, expose secrets, or bypass a resource budget

The project will treat authority widening, evidence-strength inflation, protected-transport bypass, secret disclosure and silent fail-open behavior as high-priority classes.
